Acerca del Blog Django

Este proyecto representa la consolidación final de la formación en Python y Django, implementando una arquitectura web completa, segura y escalable.

Puntos Destacados

Rutas Protegidas & Auth

Gestión de usuarios completa, protección de vistas a nivel de backend mediante mixins y verificación de autoría en edición/borrado.

Multimedia & Templates Robustos

Carga de imágenes vía Pillow con fallback elegante para posts sin portada, asegurando estabilidad visual en todo momento.

Motor de Búsqueda

Filtro en tiempo real por título, subtítulo o contenido de las publicaciones, con feedback cuando no hay resultados.

Perfil Personalizado

Modelo Profile 1 a 1 con el usuario para avatar, biografía y sitio web, configurable desde la interfaz web.

Tecnologías Utilizadas
Python 3.10+ Django 5 SQLite Bootstrap 5 Pillow python-decouple
Código Fuente en GitHub
Estructurado con historial limpio de commits, configurado con variables de entorno y listo para su clonación y despliegue.
